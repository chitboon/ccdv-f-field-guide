How the items are built

Most published question banks give themselves away: the correct answer is the longest option, or the wrong ones are padded filler you can eliminate without knowing anything. Three checks in tools/ run against every set — answer-position balance by chi-square, option-length rank spread, shared phrasing between options, verbatim overlap against source material, and near-duplicate detection across the whole bank. A fourth measure keeps absolute language ("never", "always", "entirely") at the same rate in correct answers as in distractors, so register cannot be used as a shortcut.
