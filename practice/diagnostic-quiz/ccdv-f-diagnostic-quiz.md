**1.** What is the fundamental mechanism behind Claude's text generation?

A. Next-token probability prediction based on context and trained weights.  
B. Rules-based template matching in enterprise application configurations.  
C. Direct SQL query execution over an internal knowledge graph database within standard production deployment environments.  
D. Deterministic logic tree evaluation under system pipeline settings.  

<details><summary>Answer</summary>
**A — Next-token probability prediction based on context and tr...**
LLMs generate text by sequentially predicting the highest-probability next token based on learned weights and context.
</details>

**2.** Which HTTP status code indicates that an application has exceeded Anthropic API rate limits?

A. 400 Bad Request in client parameter validation in client applications.  
B. 429 Too Many Requests when request quotas are exceeded.  
C. 401 Unauthorized due to invalid authentication key settings.  
D. 529 Overloaded during peak API server infrastructure load within standard production deployment environments.  

<details><summary>Answer</summary>

**9.** What is the primary function of prompt caching in the Claude API?

A. Reuse pre-parsed prefix context across API calls to reduce latency and token costs within standard production deployment environments.  
B. Automatically store user queries in a database for analytics in client applications.  
C. Cache API responses locally on the client device to avoid network requests.  
D. Store model weights in client memory to enable offline inference in client applications.  

<details><summary>Answer</summary>
**A — Reuse pre-parsed prefix context across API calls to reduc...**
Prompt caching reuses previous prompt prefix tokens (e.g. system prompts, large documents), saving up to 90% cost and latency.
</details>

**10.** What is the default minimum TTL (Time-To-Live) for a prompt cache block in the Claude API?
